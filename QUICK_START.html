🎨 ChaiTailwind Quick Start

Get up and running in 5 minutes

⚡ Installation

Option 1: Direct Script Tag (Easiest)

<script src="https://your-domain.com/chaitailwind.js"></script>

Option 2: From CDN

<script src="https://cdn.example.com/chaitailwind.min.js"></script>

Option 3: NPM

npm install chaitailwind

Option 4: Local File

<script src="./chaitailwind.js"></script>

⏱️ 5-Minute Setup

1 Create an HTML file
<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First ChaiTailwind Page</title> </head> <body> <!-- Your content goes here --> <!-- Script at the end --> <script src="chaitailwind.js"></script> </body> </html>
2 Add chai-* classes to elements
<div class="chai-p-20 chai-bg-blue chai-rounded-lg"> <h1 class="chai-text-3xl chai-font-bold chai-text-white"> Hello ChaiTailwind! </h1> </div>
3 Open in browser - Done! ✨

❓ Common Issues

🔍 Issue: Styles not applying?

  • Make sure script is loaded after your HTML
  • Check class names start with "chai-"
  • Verify the utility name is correct
  • Open dev tools console for debug info

🔍 Issue: Adding elements dynamically?

  • After adding new elements, call chai.rescan()
  • Or use a MutationObserver to auto-rescan

🔍 Issue: Conflicting CSS?

  • ChaiTailwind uses inline styles (highest specificity)
  • Remove conflicting CSS rules if needed
  • Check browser dev tools for style conflicts
