ChaiTailwind - Integration Guide

Advanced patterns and real-world integration examples

1. Basic Integration

The simplest way to get started:

<!-- At the end of your body tag --> <script src="path/to/chaitailwind.js"></script> <!-- Then use chai-* classes --> <div class="chai-p-20 chai-bg-blue chai-text-white"> Hello World! </div>

The library auto-initializes when DOM is ready.

2. React Integration

Use ChaiTailwind in React components:

import ChaiTailwind from 'chaitailwind'; import { useEffect } from 'react'; function App() { useEffect(() => { const chai = new ChaiTailwind({ debug: false }); chai.scan(); // Listen for DOM changes const observer = new MutationObserver(() => { chai.rescan(); }); observer.observe(document.body, { childList: true, subtree: true }); return () => observer.disconnect(); }, []); return ( <div className="chai-p-20 chai-bg-blue chai-text-white"> Hello React! </div> ); } export default App;

3. Vue.js Integration

Integrate with Vue 3:

<script setup> import { onMounted } from 'vue'; import ChaiTailwind from 'chaitailwind'; onMounted(() => { const chai = new ChaiTailwind({ debug: true }); chai.init(); }); </script> <template> <div class="chai-p-20 chai-bg-blue chai-text-white"> Hello Vue! </div> </template>

4. Dynamic Content

Update ChaiTailwind when DOM changes:

const chai = new ChaiTailwind(); chai.init(); // When adding new elements dynamically const newElement = document.createElement('div'); newElement.className = 'chai-p-10 chai-bg-red chai-text-white'; newElement.textContent = 'New Element'; document.body.appendChild(newElement); // Re-scan to apply styles to new elements chai.rescan();

5. Custom Utilities

Extend ChaiTailwind with your own utilities:

const chai = new ChaiTailwind(); // Add single custom utility chai.addUtility('gradient-sunset', () => ({ background: 'linear-gradient(135deg, #f093fb 0%, #f5576c 100%)', color: 'white' })); // Add multiple utilities at once chai.addUtilities({ 'card-shadow': () => ({ boxShadow: '0 10px 30px rgba(0,0,0,0.3)' }), 'button-hover': () => ({ transition: 'all 0.3s ease' }), 'blur-background': (value) => ({ backdropFilter: `blur(${value}px)` }) }); chai.init(); // Usage in HTML: // <div class="chai-gradient-sunset chai-card-shadow">...</div> // <div class="chai-blur-background-10">...</div>

6. Configuration

Customize ChaiTailwind behavior:

const chai = new ChaiTailwind({ prefix: 'tw-', // Change prefix (default: 'chai-') debug: true // Enable debug logging (default: false) }); chai.init(); // Useful for large projects: const debugChai = new ChaiTailwind({ debug: true, // See what's happening prefix: 'chai-' });

7. Performance Optimization

Best practices for production:

// ✅ GOOD: Initialize once const chai = new ChaiTailwind({ debug: false }); chai.init(); // ✅ GOOD: Batch DOM updates const fragment = document.createDocumentFragment(); for (let i = 0; i < 100; i++) { const el = document.createElement('div'); el.className = 'chai-p-5 chai-bg-blue'; fragment.appendChild(el); } document.body.appendChild(fragment); chai.rescan(); // ❌ AVOID: Multiple rescan calls element1.appendChild(el); chai.rescan(); element2.appendChild(el); chai.rescan(); // Bad! // ✅ GOOD: Batch rescan element1.appendChild(el); element2.appendChild(el); chai.rescan(); // Once!

8. Debugging

Use debug mode to troubleshoot:

// Enable debug logging const chai = new ChaiTailwind({ debug: true }); chai.init(); // Output in console: // "ChaiTailwind initialized" // "Applied p-20 to <div>" // "Applied bg-blue to <div>" // "ChaiTailwind scan complete. Processed X elements" // Check if utility exists if (chai.utilities['custom-utility']) { console.log('Utility found!'); }

9. Using DevTools

Debug ChaiTailwind styles in browser:

// In browser console: const chai = window.ChaiTailwind; const chaiInstance = new chai({ debug: true }); // View applied styles on element const el = document.querySelector('[class*="chai-"]'); console.log(el.style); // See inline styles // Test adding custom utility chaiInstance.addUtility('test', () => ({ color: 'red' }));

10. Error Handling

Handle edge cases gracefully:

const chai = new ChaiTailwind({ debug: true }); // Invalid utility - warning in console // <div class="chai-invalid-utility"> // Warning: Unknown utility: invalid // Non-numeric value - handled gracefully // <div class="chai-w-auto"> // width: auto ✓ // Mixed utilities - works fine // <div class="chai-p-10 normal-class chai-bg-blue"> // Only chai-* classes are processed chai.init();

12. Troubleshooting

Q: Styles not applying?

A: Check: 1. Script is loaded after DOM content 2. Class names follow chai-* pattern 3. Utility name is valid 4. Call init() or rescan() after adding elements

Q: Performance issues?

A: Try: 1. Disable debug mode (debug: false) 2. Reduce number of chai-* classes 3. Batch DOM updates and rescan once 4. Use custom prefix for targeted scanning

Q: Works locally but not in production?

A: Check: 1. Script path is correct 2. No CSP violations 3. DOM is ready when script runs 4. No conflicting CSS or scripts
